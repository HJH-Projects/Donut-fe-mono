# 룩 스펙

## 개요
- **URL**: `/look`
- **설명**: 저장된 룩 카드 목록을 보여준다.

## 0. 라우팅 전략
- **구조**: `app/look/page.tsx`
- **페이지 레이어**: `page/look/ui/LookPage.tsx`

## 1. UI/UX 계획
### 구조
- 룩 카드 목록
  - 별칭, 추가 날짜, 태그 목록
  - 추가한 옷 이미지(소형 정사각형)
  - 즐겨찾기/공유/수정/삭제
- 우측 하단 + 버튼: 룩 생성

## 2. 데이터 전략
### API 계약(도메인 분리)
- **룩 목록**: `GET /looks`
- **룩 생성**: `POST /looks`

## 3. 에러/엣지 케이스
| 케이스 | 조건 | 동작 |
|---|---|---|
| 목록 없음 | 0개 | 빈 상태 UI |

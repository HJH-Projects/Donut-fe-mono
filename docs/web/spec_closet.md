# 옷장 스펙

## 개요
- **URL**: `/closet`
- **설명**: 카테고리별 내 옷 이미지 목록을 보여준다.

## 0. 라우팅 전략
- **구조**: `app/closet/page.tsx`
- **페이지 레이어**: `page/closet/ui/ClosetPage.tsx`

## 1. UI/UX 계획
### 구조
- 카테고리 탭 또는 섹션
- 각 카테고리별 옷 이미지 그리드
- 우측 하단 + 버튼: 파일/카메라 선택
- 각 옷 이미지 우측 하단: 즐겨찾기(하트)

## 2. 데이터 전략
### API 계약(도메인 분리)
- **의류 목록**: `GET /clothes`
- **의류 등록**: `POST /clothes`
- **업로드 URL 발급**: `POST /uploads/presign`
- **업로드 완료 처리**: `POST /uploads/complete`

## 3. 에러/엣지 케이스
| 케이스 | 조건 | 동작 |
|---|---|---|
| 목록 없음 | 0개 | 빈 상태 UI |

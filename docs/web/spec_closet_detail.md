# 옷 상세 스펙

## 개요
- **URL**: `/closet/[id]`
- **설명**: 선택한 옷의 상세 정보를 보여준다.

## 0. 라우팅 전략
- **구조**: `app/closet/[id]/page.tsx`
- **페이지 레이어**: `page/closet/ui/ClosetDetailPage.tsx`

## 1. UI/UX 계획
### 구조
- 상단 헤더: 뒤로가기 / 아이템상세 / 공유
- 이미지: 정사각형
- 하단 정보
  - 별칭
  - 카테고리, 시즌, 색상, 브랜드, 소재, 사이즈
  - 메모 영역(사용자 입력)

## 2. 데이터 전략
### API 계약(도메인 분리)
- **의류 상세**: `GET /clothes/{id}`
- **의류 수정(메타/메모 포함)**: `PATCH /clothes/{id}`
- **의류 삭제**: `DELETE /clothes/{id}`

## 3. 에러/엣지 케이스
| 케이스 | 조건 | 동작 |
|---|---|---|
| 상세 조회 실패 | API 오류 | 에러 UI |

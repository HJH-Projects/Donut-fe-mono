# 룩 등록 스펙

## 개요
- **URL**: `/look/new`
- **설명**: 룩 이름/태그를 설정하고 옷장을 선택해 룩을 만든다.

## 0. 라우팅 전략
- **구조**: `app/look/new/page.tsx`
- **페이지 레이어**: `page/look/ui/LookCreatePage.tsx`

## 1. UI/UX 계획
### 구조
- 룩 이름 입력
- 태그 선택
- 하단 옷장 목록(카테고리별)
- 선택 시 이미지 위 반투명 검정 + 체크 표시

## 2. 데이터 전략
### API 계약(도메인 분리)
- **룩 생성**: `POST /looks`
  - 이름, 태그, 선택 옷 목록
- **의류 목록(선택용)**: `GET /clothes`

## 3. 에러/엣지 케이스
| 케이스 | 조건 | 동작 |
|---|---|---|
| 저장 실패 | API 오류 | 에러 UI |

# 마이 스펙

## 개요
- **URL**: `/my`
- **설명**: 사용자 프로필과 설정, 고객지원, 로그아웃을 제공한다.

## 0. 라우팅 전략
- **구조**: `app/my/page.tsx`
- **페이지 레이어**: `page/my/ui/MyPage.tsx`

## 1. UI/UX 계획
### 구조
- 프로필: 닉네임/이메일
- 통계 카드: 옷장/룩/등급 (1행 3열)
- 등급 진행률 안내
- 설정: 온도 단위/언어/알림
- 고객지원: 도움말/문의
- 로그아웃 버튼

## 2. 데이터 전략
### API 계약(도메인 분리)
- **내 프로필**: `GET /users/me`
- **프로필 수정**: `PATCH /users/profile`
- **사용자 초기화(주의)**: `POST /users/reset`
- **통계(임시)**: `GET /users/stats` (프론트 API 호출 함수 내부에서 mock 반환)

## 3. 에러/엣지 케이스
| 케이스 | 조건 | 동작 |
|---|---|---|
| 정보 조회 실패 | API 오류 | 기본값 표시 |

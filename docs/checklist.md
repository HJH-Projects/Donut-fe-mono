# 작업 체크리스트 (필요 시에만 참조)

이 문서는 **실수 방지용 체크리스트**입니다.
작업 전/후에만 확인합니다.

## 작업 전
- 요구사항/스펙 확정 여부 확인
- 관련 정책 변경 필요 여부 확인 (`docs/policies.md`)
- 도메인/쿠키/리다이렉트 환경 확인
- 대상 앱/브랜치 확인

## 작업 중
- 변경 단위를 작게 유지
- 단계별 검수 지점 고정
- 임시 패치/정식 해결 구분

## 작업 후
- `pnpm --filter web build` 실행
- 디버그 로그 제거
- 문서 업데이트 필요 여부 확인
- `feature_status`는 **dev에서만** 업데이트

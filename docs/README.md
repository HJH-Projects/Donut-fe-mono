# 문서 인덱스

이 문서는 모노레포 공통 규칙의 시작점입니다.
앱별 세부 규칙은 각 앱의 `docs/`에서 확인합니다.

## 워크플로우
- `docs/workflow.md`: 공통 개발 흐름(브랜치/검증/머지)
- `docs/worktree.md`: 병렬 작업을 위한 worktree 운영
- `docs/feature_status.md`: 기능 상태 업데이트 규칙
- `docs/checklist.md`: 작업 전/후 체크리스트

## 컨텍스트 최소화 가이드
- `docs/context_loading.md`: 필요한 문서만 읽도록 범위와 조건 정의

## 규칙/구조
- `docs/conventions.md`: 공통 코딩/문서 규칙
- `docs/policies.md`: 변경 시 혼선 방지용 고정 정책
- `docs/architecture.md`: 모노레포 구조와 책임 범위
- `docs/architecture_conventions.md`: 구조 관련 보조 규칙
- `docs/pr_template.md`: PR 작성 템플릿(상세)

## 스펙
- `docs/spec_template.md`: 공통 최소 스펙 템플릿

## 기능 현황
- `docs/feature_list.md`: 모노레포 기능 현황 요약

## 앱별 문서
- `docs/web/workflow.md`: 웹 전용 워크플로우
- `docs/app/workflow.md`: 앱 전용 워크플로우
- `docs/web/coding_convention.md`: 웹 전용 컨벤션
- `docs/web/spec_template.md`: 웹 전용 스펙 확장
- `docs/web/error_log.md`: 웹 에러 로그
- `docs/web/feature_list.md`: 웹 기능 현황
- `docs/web/readme.md`: 웹 README
- `docs/app/readme.md`: 앱 README
- `docs/app/coding_convention.md`: 앱 전용 컨벤션
- `docs/app/spec_template.md`: 앱 전용 스펙 확장
- `docs/app/error_log.md`: 앱 에러 로그
- `docs/app/feature_list.md`: 앱 기능 현황

## 역할별 에이전트 가이드
- `docs/skill_design_planner.md`: 설계/플랜 에이전트
- `docs/skill_implementation_agent.md`: 구현 에이전트
- `docs/skill_review_agent.md`: 검수 에이전트
- `docs/skill_integration_agent.md`: 통합 에이전트

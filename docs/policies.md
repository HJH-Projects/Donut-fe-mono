# 공통 정책 (필요 시에만 참조)

이 문서는 **변경 시 혼선을 만드는 규칙**만 모아둡니다.
일상 작업에는 읽지 말고, **정책 변경이나 논쟁이 있을 때만** 확인합니다.

## 1) 로그인/쿠키/도메인
- 프론트: `doknot.xyz`, 백엔드: `api.doknot.xyz` 기준.
- 쿠키는 백엔드에서 `Domain=.doknot.xyz`, `Secure`, `SameSite=Lax`로 발급.
- 로그인 성공 후 라우팅은 **강제 이동(window.location.assign)** 방식 우선.

## 2) 캐싱 기준
- 좌표는 소수점 2자리로 고정해 캐시 키 안정화.
- 추천 API 캐시는 **lat/lon/gender 기준**으로 분리.
- dev 모드에서 캐시 확인은 제한적이며, prod에서 헤더 확인.

## 3) API 호출 규칙 (ky 통합)
- 서버 컴포넌트: `serverKy`
- 클라이언트 컴포넌트: `clientKy`
- `fetch` 직접 사용 금지 (업로드 PUT은 ky로 대체)

## 4) 서버/클라이언트 분리 규칙
- `*.server.ts`는 서버 컴포넌트에서만 사용.
- `*.client.ts`는 클라이언트 컴포넌트에서만 사용.
- 공용 타입은 `*.types.ts`에 둔다.

## 5) 라우팅/로딩 범위
- 홈 로딩은 `(home)` route group으로 제한.
- `loading.tsx`는 필요한 범위에만 둔다.

## 6) 공용 UI
- 뒤로가기: `BackButton` 공용 컴포넌트 사용.
- 아이콘 스타일은 공용 컴포넌트로 통일.
